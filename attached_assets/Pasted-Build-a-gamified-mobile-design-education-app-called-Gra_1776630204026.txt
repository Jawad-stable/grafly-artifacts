ELEVENLABS VOICE INTEGRATION

The ElevenLabs API key is available as an environment variable through Replit's native integration. Access it via process.env.ELEVENLABS_API_KEY — do not hardcode it or add it to .env manually.

Grafly uses ElevenLabs to give the app a consistent voice identity. Voice is used for encouragement, lesson narration cues, and feedback delivery — not for reading full lesson text.

Create a dedicated voice service file at src/services/voiceService.ts. All ElevenLabs calls must go through this service — never called directly from a component.

The voice service must expose these functions:

playStreakCelebration() — plays a short energetic encouragement line when a streak milestone is hit. Example script: "You're on fire! Keep that streak alive."

playLevelUp(levelNumber) — plays a congratulatory line on level-up. Example script: "Level [number] unlocked. You're becoming a real designer."

playLessonComplete() — plays a short positive reinforcement after a lesson. Example script: "Lesson done. XP earned. You're moving forward."

playCorrectAnswer() — plays a brief affirming sound cue. Example script: "Exactly right."

playWrongAnswer() — plays a gentle, non-discouraging cue. Example script: "Not quite — let's keep going."

playCritiqueReady() — plays when AI critique feedback arrives. Example script: "Your critique is ready. Let's see how you did."

playQualityTier(tier) — plays a tier-specific message. For "excellent": "Outstanding critique. That's expert-level thinking." For "good": "Solid work. You're developing a strong design eye." For "needs_development": "Good effort. Every critique makes you sharper."

All voice lines must be pre-generated using the ElevenLabs text-to-speech API and cached locally using expo-file-system so they don't re-fetch on every trigger. On first app launch, pre-generate and cache all static voice lines in the background.

Use a single consistent ElevenLabs voice across all lines. Recommended voice: "Jon" (voice_id: MFZUKuGQUsGJPQjTS4wC) or allow override via ELEVENLABS_VOICE_ID env variable.

Use the ElevenLabs streaming API for dynamic voice lines (like playLevelUp where the level number changes). Use the standard TTS API for static lines and cache them.

Audio playback must use expo-av (Audio.Sound). Each playback function loads the sound, plays it, then unloads it to free memory. Never play two voice lines simultaneously — cancel any active sound before playing a new one.

Voice is enabled by default. Add a toggle in the Profile screen under Settings: "Voice Feedback" on/off. Store this preference in AsyncStorage and check it in voiceService before every playback call.

The ELEVENLABS_API_KEY must be stored in .env and accessed only through the Supabase Edge Function proxy — never exposed in client-side code. Create an edge function at supabase/functions/tts/index.ts that accepts a POST request with { text, voice_id } and returns the audio stream from ElevenLabs.


UI/UX REQUIREMENTS — TOP PRIORITY

The UI must feel premium, playful, and motion-rich. Reference: Duolingo meets a modern design tool. Every screen must feel intentional and alive.

Visual Language

Dark mode default, light mode supported via Appearance API.
Primary palette: (#DEE0ED), (#21263F), (#00A4FA), (#E3ED43), (#FF7BD0).
Neutral base: #0F0F14 (background), #1A1A24 (card), #2A2A38 (border/divider).

Cards: borderRadius 20–28, subtle shadow, glassmorphism via semi-transparent backgrounds + expo-blur.
Iconography: @expo/vector-icons (Ionicons), 24px, animated on tap.

Motion and Microinteractions — CRITICAL

Use react-native-reanimated v3 for all animations. Use react-native-gesture-handler for drag interactions.

XP pop-up: withSpring scale-in + translateY float up + FadeOut after 1.2s.
Heart loss: translateX shake oscillation + red background flash. Then trigger playWrongAnswer().
Level-up: full-screen confetti (react-native-confetti-cannon) + scale-in card. Then trigger playLevelUp(level).
Streak flame: looping pulse (scale 1 to 1.1 to 1, withRepeat).
Streak milestone hit: trigger playStreakCelebration() + confetti burst.
Skill tree node unlock: withSpring scale from 0.6 to 1 + glow fade-in.
Lesson correct answer: green border + checkmark scale-in. Trigger playCorrectAnswer().
Lesson wrong answer: red border + translateX shake. Trigger playWrongAnswer().
Lesson complete: post-lesson summary appears. Trigger playLessonComplete().
AI critique feedback arrives: cards stagger in. Trigger playCritiqueReady(), then playQualityTier(tier).
Screen transitions: Expo Router stack with custom spring animation.
Bottom sheet: react-native-bottom-sheet with spring physics.

GAMIFICATION LOGIC

XP: lesson complete = 20, perfect quiz = +10, critique submit = 15, excellent critique = 25. Never deducted.
Coins: 5/lesson, 10 bonus on first lesson of day, 25/level-up, variable streak milestones.
Hearts: 5/day free tier. -1 per wrong answer. Regenerate 1 per 4 hours. 0 hearts = lesson blocked + paywall triggered.
Streak: 1+ lesson or critique per calendar day. Shields protect 1 missed day. Max 3 shields held.
Leaderboard: XP earned current week. Resets Monday 00:00 UTC. Divisions: Bronze, Silver, Gold, Platinum, Diamond.
Level thresholds: exponential curve. Level-up triggers confetti + coin bonus + voice line.

All gamification state lives in Zustand. All server sync via React Query + Supabase edge functions.
